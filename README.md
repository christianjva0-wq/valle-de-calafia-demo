# Valle de Calafia · Demo ceremonial

Sitio de demostración con salón ceremonial, terciopelo burdeos, nogal, detalles dorados y movimiento 3D pronunciado. Diseño adaptable a móvil y escritorio.

## Presentar la demo

1. En GitHub, pulsa **Code → Download ZIP** y descomprime el archivo.
2. Abre **index.html** en Chrome, Edge o Firefox. Todo está integrado: imagen, estilos y JavaScript. No requiere instalación ni conexión para sus recursos visuales.
3. Desplázate por la portada para mostrar el acercamiento al salón.
4. En Simbolismo, muestra el libro tridimensional, su respuesta al cursor y las pestañas.
5. Explora la cronología, las fuentes y el contacto institucional.

[Demo alojada](https://valle-de-calafia.christianjva0.chatgpt.site) — conserva acceso privado del propietario.

## Implementación

Un único HTML autocontenido, sin paquetes, compilación, cookies, analítica ni formularios. Incluye buscador de secciones y navegación por teclado. Respeta la preferencia de movimiento reducido.

Exportado de la versión original 1e33b3c82c3cefc0a8c8cff63b2c5c7bcdafc9bc. Solo se integraron los recursos dentro del HTML; se conserva el diseño y comportamiento.
